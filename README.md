# Archmage — descargas

RPG táctico por turnos en pixel art. Aquí solo están los ejecutables: ve a **Releases** y baja la versión más nueva.

- Windows: `Archmage-<versión>-windows.zip` → descomprime y abre `Archmage.exe` (si Windows avisa: «Más información» → «Ejecutar de todas formas»).
- El juego se actualiza solo desde el título.
